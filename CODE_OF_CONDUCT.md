# Code of conduct

Be respectful, explain technical disagreements with evidence, and welcome contributors regardless of experience or background. Harassment, discriminatory abuse, threats, doxxing, impersonation, spam and nonconsensual account linking are prohibited. Protect household privacy; never request credentials in a public report.

Report conduct privately to [adidshaft@kyokasuigetsu.xyz](mailto:adidshaft@kyokasuigetsu.xyz). Maintainer [@adidshaft](https://github.com/adidshaft) receives reports; there is no separate moderation team or promised response deadline. Include the context and requested resolution without unnecessary personal information.

Responses are proportionate: clarification or a private warning, content removal, temporary restriction, or permanent exclusion for serious/repeated harm. The maintainer considers context and gives an explanation where privacy permits. Appeal by replying to the same private address with new evidence or a specific concern. A conflict involving the maintainer is recorded and referred to another maintainer if one becomes available; independent review is not presently guaranteed. Public retaliation is prohibited. See [governance](https://github.com/adidshaft/grok-gadgets/blob/main/GOVERNANCE.md).

This policy covers repository discussions, reviews, project community spaces and representation of this project. Live moderation and Reddit changes are separate authorized operations.
