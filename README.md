# Grok Gadgets ESP32 SDK

Reusable C++ capability and transport SDK for ESP32 gadgets exclusively connecting to the Grok Gadgets gateway. The first consumer is standalone Arduino firmware for **M5Stack AtomS3 Lite C124**. Local alpha under development; no physical board or real Grok Bot is available.

Original code: Apache-2.0. Independent project, unaffiliated with xAI or M5Stack.

See [contribution instructions](CONTRIBUTING.md), [local issues](planning/issues.md), and shared [community policies](../grok-gadgets/community/README.md). No public repository exists yet.
